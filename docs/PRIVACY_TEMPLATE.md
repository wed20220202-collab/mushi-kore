# プライバシーポリシー（ひな型）

## 取り扱う情報

Googleアカウントの基本情報、撮影画像、AI判定結果、撮影日時、任意の位置情報、タグ・メモ、利用・エラー履歴を取り扱います。

## 利用目的と保存先

図鑑機能、AI判定、検索、障害対応、不正利用防止に利用します。圧縮済み画像は運営者が管理する非公開Google Driveへ、図鑑メタデータはCloud Firestoreへ保存します。画像は一般公開せず、認証と所有権確認を経た経路でのみ表示します。運営者または権限を持つ管理者が、運用上必要な範囲で画像へアクセスする可能性があります。

## 外部送信・位置情報

虫判定のため画像をGemini APIへ送信します。利用条件によっては、送信画像・プロンプト・回答がGoogleの製品改善や人による確認に使われる可能性があります。人物、住所、車両番号などの個人情報が写る画像は送信しないでください。位置情報は任意で、AI判定APIへは送信せず、拒否しても登録でき、後から修正・削除できます。

## 保存期間・削除・問い合わせ

アカウント存続中またはサービス提供に必要な期間保存し、削除操作後は通常ゴミ箱を経て削除します。利用者は記録単位またはアカウント単位で削除を申請できます。公開前に問い合わせ先メールアドレス、運営者情報、改定日を追記してください。
